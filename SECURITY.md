# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please don't report security problems in public issues. Use GitHub's
[private vulnerability reporting](https://github.com/muhamadsyahrulmubarok/pocketbeat/security/advisories/new)
instead, with steps to reproduce and the PocketBeat and browser versions affected.

You can expect a first response within 7 days.
